## Findings and corrections

**AU-01 — Authored engineering sources could bypass production isolation through raw or URL imports. Corrected.** The inherited build guard recognized the internal UI, component metadata and generated references, but did not recognize the repository's authored `docs/` sources or README/instruction files. A real Vite regression importing `docs/project/human-actions.md?raw` from the product home failed with `Missing expected rejection`: the product bundle accepted the guide. The ordinary artifact was not importing this source; this finding concerns a missing fail-closed boundary, not evidence of an already published document leak.

The guard now recognizes authored internal sources within this checkout and rejects their included imports, including `?raw` and `?url`. The check preserves third-party package notices and independent product-help sources. New real-build regressions cover the internal guide as raw text and an asset URL, plus root instructions. Selection tests cover authored guides and package README sources. Existing default/neutral/product-help/internal build checks and accidental catalog/metadata/OpenAPI import checks remain in place. The regression fails before the correction and both documentation-build tests pass afterward; no assertion, timeout, permission or security control is relaxed.

No accidental product-functionality change was identified in the remaining reviewed diff. The two runtime-facing upgrade edits outside portal/build tooling are intentional: the sidebar/home developer-link constant follows the new compile-time selection, and a web-hosting comment names the new build flag. Product authentication and server-side authorization code are unchanged.
